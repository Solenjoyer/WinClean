# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful and constructive, assume good faith, keep discussions about the work. Harassment of any kind is not tolerated.

Reports can be sent privately through GitHub's "Report content" feature on the item in question, or by opening a private vulnerability report (Security tab) if the matter should not be public. Maintainers will respond within seven days and act in confidence.
