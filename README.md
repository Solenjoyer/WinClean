# WinClean

A free, open-source Windows system monitor and cleanup utility for developers and power users.

WinClean answers three questions at a glance:

1. What is using my CPU, memory and disk?
2. What is taking up space on my computer?
3. Is my system healthy and up to date?

It groups processes by application (so "Cursor", "Claude Code", "Docker Desktop" or "WSL" show up as one line with their real memory footprint), scans drives on request, finds the caches and leftovers developers accumulate, and cleans only what you have previewed and confirmed. Everything runs locally: no account, no telemetry, no analytics, no network access unless you click a link.

WinClean is under active development and not yet released. Build and packaging instructions, screenshots and the full feature list will land here as the first release approaches.
